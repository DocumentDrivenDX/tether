# Contextual RAM credential-factory operator

This is a source-only archive of the private operator and offline controls. It records an explicitly bounded contextual retry policy; it does not claim that the SDK rejection cause was proven or that any live selected-profile qualification passed. The original archived RAM operator remains separate and unchanged.

`operator.py.txt` and `test_controls.py.txt` are exact copies of the reviewed private files. `policy-and-hashes.json` is the exact private control manifest. `archive-index.json` binds these copies to source-map 27 and labels their evidence scope.
