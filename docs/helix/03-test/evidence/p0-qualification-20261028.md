## Accepted history-link source slice

Source commit `48618e106d55491c0793d744ba7a629cdb5b3a1b` (tree `f003535bde9775e2a8b67a42364fd3dd56534439`) closes the previously missing CONTRACT-005 accepted-replacement mechanism. The complete local `make check` run on the same source and test files passed on macOS with Python 3.11.17: **1,701 tests in 79 bounded groups, 90% aggregate branch coverage**. Ruff, format, Pyright, file size, ceiling, layer, and dependency checks passed. The local run log is outside Git; it is not a hosted or cross-platform result. An earlier full attempt hit a timing-sensitive existing PostgreSQL lifetime test; the isolated rerun and complete final run passed without changing its timeout or assertion.

`HistoryLink` records the source message index, prior and verified refs, and canonical digest. Binding requires current `link_history` authority, a committed source, ready equivalent content, a reachable prior ref, finite cycle/hop checks, and a lease-fenced journal append. Readers choose the newest reachable accepted replacement at a pinned journal head, reauthorize content, and report denied, unavailable, or integrity-error states explicitly. The JSONL and PostgreSQL lookup group is indexed; archive reads verify a bounded complete entry prefix and refuse an incomplete or over-limit prefix rather than omit links silently.

Executed new cases cover latest-link and pinned-head selection, malformed/cyclic/overlong chains, scope and codec mismatches, unsupported link schema versions, JSONL unknown acknowledgment and idempotent reopen, memory/JSONL replacement readiness, content mismatch refusal, call-detail and approval-result reads, concurrent page pinning, archive slots, and PostgreSQL indexed lookup. Generic external-source readiness now includes `unsupported`. These cases qualify the selected local profiles only; model summary fidelity, server-specific token accounting, and final stable-version installed artifacts remain P0 decisions. Later DS4 evidence below narrows the first two gaps without proving a general bound.
